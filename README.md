# CLI CSV Data Viewer
A command-line tool for viewing and displaying CSV files made as a simple learning project.

## Features
- Parse and display CSV files
- Dynamic column alignment for readability
- Handles various CSV formats

## Requirements
- C compiler (e.g gcc, clang, etc.)

## Usage
```bash
gcc CCDV.c -o CCDV
./CCDV filename.csv 
`````

## Project Files 
- CCDV.c (Main Source Code)
- DAY1.txt, DAY2.txt, DAY3.txt (Learning Documentation)
- Inspo.png (Project Inspiration)
- Test CSV files for development

This project was developed as a learning excercise in C programming, focusing on:
